# Jair Martins — Gerador de Foto

Ferramenta oficial para apoiadores criarem e baixarem uma foto personalizada com as molduras da campanha.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Cloudflare Pages

- Framework: Next.js (Static HTML Export)
- Build command: `npx next build`
- Output directory: `out`
- Production branch: `main`
